# Eúzēn · Closed test

Open your approved test URL and sign into Vercel if prompted. Open the beta guide under app installation, updates and help. The guide supports German, English and Greek; the app interface supports German and English.

Allow 15–20 minutes: Add two exercises, build a workout with repetitions or a timer, complete a short session and save a note. Reopen the app and check sync status. Sign in under Settings & Data using your email code for account sync. Enter codes only in Eúzēn.

Guest data is local and separate from your account. Import requires a preview, backup and explicit confirmation. Regularly export a JSON backup; clearing browser data can remove local content. Backups contain sensitive data.

Optional: Safari → Share → Add to Home Screen, or Chrome → Install app. After offline readiness is confirmed, edit a small note offline, reopen, reconnect and check sync. Sign into a second device with the same account to compare data.

For conflicts, back up first and compare versions. Save pending changes before signing out and switching accounts. Local reset does not reset your cloud account. Contact support for deletion requests.

Before important updates, back up, finish training, close all old app windows and reopen. Prepare feedback in the guide, review the email draft and send it yourself. Never include codes, tokens, private training content or backups. Support: info@nap-studios.de, +49 176 97529412.
